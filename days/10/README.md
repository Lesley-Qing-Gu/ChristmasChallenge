# Podcast Desk 🎙️

Edit a podcast by editing its transcript. It runs on your own computer, and you don't need an API key.

- `index.html`: the Day 10 page (demo video, download, how to run it)
- `podcast-desk/`: the app itself; see [its README](podcast-desk/README.md)
- `podcast-desk.zip`: the same folder, zipped for download
- `demo.mp4`, `demo.jpg`: the demo. The episode in it is made up and voiced by a speech model (Kokoro).
