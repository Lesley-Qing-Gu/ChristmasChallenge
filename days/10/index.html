Podcast Desk

Edit a podcast like a document. Delete the words and the audio goes with them.

0:32For me it's my neighbour's, um, my neighbour's dog. It barks at the moon.

Download for Mac, Windows, Linux 76 KB View the source

A one-minute demo, sound on. The episode in it is made up and voiced by a speech model; the music is synthesized too.

What it does

I built it to edit my own podcast, because scrubbing through waveforms for every “um” took longer than recording the episode.

01Rough cut, automatically

Upload a recording. It's transcribed, split by speaker, and the ums, uhs, false starts, coughs, cross-talk and long gaps are cut before you even open it.

02Edit text, edit audio

Deleted words turn into red strike-through, and moved passages get a green double underline, like tracked changes in Word. Undo always works.

03Hear the edit

Press space and you hear the edited episode, not the original. Every word lights up as it's spoken.

04Fillers in one go

Tick “um”, “you know”, “I mean” or anything you add. You see every hit in context before it goes.

05Pace and sound

Make every pause between sentences the same length, slow down one speaker without changing their pitch, level the volume or remove noise, then A/B the result.

06Export, and show notes

A clean mp3 with smooth cuts. If Claude Code is installed, it also writes show notes with timestamps that match the edit.

Run it on your computer

It's a small local web app: a Python server on your computer and an editor in your browser. Your recordings never leave the machine. Takes about ten minutes the first time.

Install Python and ffmpeg

Python 3.10 or newer from python.org, then brew install ffmpeg.

Python 3.10 or newer from python.org (tick “Add to PATH”), then winget install ffmpeg.

sudo apt install python3 python3-venv ffmpeg or your distro's equivalent.

Open Terminal in the folder and run ./setup.sh. On an M-series Mac it also installs the fast GPU transcriber.

Start it

Run ./start.sh. It opens in your browser at localhost:8765.

Drop in an episode

Pick the language and the number of speakers. The first run downloads the Whisper model (about 1.5 GB); after that everything works offline.

Does it need an AI API key?

No. The models run on your own computer, for free.
